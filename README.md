# Swahili AI Scorecard

A small test of how AI models handle everyday Kenyan Swahili.

- `FINDINGS.md`: results and corrections from testing Gemini (Auto mode, Gemini 3 family) on 20 prompts.
- `index.html`: the scorecard page. It holds the 20 prompts, the scoring rubric (accuracy, fluency, cultural fit, each 1–5) and a board where you can score any model. Open it in a browser; scores are saved in that browser only.

## Prompts

Twenty everyday prompts: proverbs, M-Pesa, county services, farming, and mixed Swahili, English and Sheng. Run each one in a new chat and score the answer.

## Limits

One model, one run, scored by one person. Corrections to Kenyan procedures should be checked against official sources.
